# README

Oleo Ventures is a local-first multi-agent company. Nick is Founder/CEO; Dex is Chief of Staff. The company assembles the smallest capable team per objective rather than running a large roster of permanently active agents.

**Status:** V0 readiness assessed (see docs/V0_READINESS.md) — one GPU-resident 7-8B model at a time, ~1-2 concurrent Ollama-bound calls, ~4-6 concurrent non-LLM workers. Real VRAM unconfirmed pending nvidia-smi check.
